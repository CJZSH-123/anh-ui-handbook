# 安徽大学学生手册 · 下滑式查询网页

把《学生手册电子版.doc》的内容做成一个可以下滑阅读、按目录跳转、按关键词检索、
并且能自己加书签的网页。纯静态，不需要服务器，双击 `index.html` 就能用。

## 怎么用

直接打开 `index.html`（双击即可），或者在本目录跑一个本地服务：

```
python -m http.server 5178
```

然后浏览器访问 http://127.0.0.1:5178/

操作方式：

- **下滑阅读**：整本手册按原文顺序连续排下来，文档标题、章标题有色区分。
- **目录跳转**：左侧「目录」按手册原有的 10 个部分、52 个条目排列，点一下就跳过去。
- **关键词检索**：上方搜索框输入关键词，下拉里显示每处命中的位置和上下文，点一条就跳过去；
  `Ctrl/Cmd + K` 或 `/` 聚焦搜索框，`↑↓` 选择、`Enter` 跳转。
- **书签**：鼠标移到任意一段，点「书签」，起个自己的名字保存。左侧切到「书签」页签可以
  改名、删除、一键跳回。书签存在浏览器本地，换电脑或清缓存会丢。
- **书签备份**：「书签」页签底部有「导出备份 / 导入备份」。导出会给你一段以 `AHDX1.` 开头
  的文字，把它存进备忘录或发给自己；以后清了浏览器数据、换了设备，粘回「导入备份」就能恢复。
  这是目前唯一可靠的备份方式——书签默认只存在本机浏览器里。
- **使用说明**：第一次进站会自动弹出；关掉后想再看，点顶部右侧的「?」随时打开。
- **跨设备同步**（需先部署到 Vercel 并接入数据库，见 `DEPLOY.md`）：在「书签」页签里点
  「开启同步」会得到一串 12 位同步码；在手机或别的浏览器输入同一个码，书签即可互通。
  开启后本机书签变化会自动上传，打开页面时会自动取回。只上传书签的名字和段落位置，不含正文。

### 在手机上用

两种方式，任选：

1. **单文件版（最省事）**：`dist/学生手册查询.html` 是一个把样式、脚本、数据全部打包进去的
   网页，399 KB。发到手机（微信、QQ、邮件都行），用浏览器打开就能用，不需要联网、不需要服务器。
   手机上「书签 / 复制」按钮是常驻显示的，书签弹层贴在屏幕底部。
   内容更新后重新生成：`python tools/build_single.py`

2. **局域网访问（内容实时、不用传文件）**：双击 `start-server.cmd`，窗口里会打印一个
   `http://192.168.x.x:5178` 的地址；手机连上同一个 Wi-Fi，用浏览器打开这个地址即可。
   第一次运行时 Windows 可能弹出防火墙询问，选「允许访问」。
   关掉那个黑窗口就停止服务。

## 目录与内容

- 正文共 2003 段、约 10.8 万字。
- 其中 **9 份文件**在原始 Word 里缺失（扫描缺页），由补充材料录入，目录和正文里都标了
  「补充」/「补充录入」：
  本硕博一体化贯通培养试点实施办法、微专业管理办法(试行)、服兵役学生国家教育资助实施细则、
  推荐优秀应届本科毕业生免试攻读研究生工作实施办法（含素质评价项目一览表）、
  中国共产主义青年团纪律处分条例(试行)、中国共产主义青年团纪律处分工作规则(试行)、
  心理健康科普、学生服务热线、学生承诺书。
- 目录里还有 2 项正文确实没有内容（不在扫描件里），点它会退化为按标题搜索：
  安徽大学学生海外交流学习资助管理办法(修订)、关于加强学校大学生征兵工作的实施意见(修订)。
- 工商文档对「安徽大学学位授予工作实施细则(修订)」与「安徽大学学士学位授予工作实施细则(修订)」
  在原件中内容互相交错，网页里两条都指向同一区块。

## 目录结构

```
index.html              页面
assets/styles.css       样式
assets/app.js           交互（检索、目录、书签）
data/handbook.js        构建产物：正文 + 目录 + 位置索引（不要手改）
dist/学生手册查询.html   单文件版（发到手机上用）
start-server.cmd        局域网访问用的一键启动脚本
source/handbook-raw.txt 从 .doc 提取出的原始文本
source/toc.txt          目录（一行一个条目，# 开头是部分标题）
source/supplements/     补充材料（9 份），index.json 记录各自插入位置
tools/                  doc_extract.py 提取、build_data.py 构建、build_single.py 打包单文件
api/sync.js             Vercel Serverless 函数：书签跨设备同步接口
DEPLOY.md               上线步骤（Vercel / GitHub Pages）与同步配置
```

## 重新构建

原始文件是 WPS 生成的 Word 97 文档（扫描识别稿），提取和构建分两步：

```
python tools/doc_extract.py <学生手册.doc> source/handbook-raw.txt
python tools/build_data.py --report      # --report 会打印目录匹配情况
python tools/build_single.py             # 重新打包手机用的单文件版
```

本地想试跨设备同步（内存版假后端，仅供测试）：

```
node tools/mock-sync-server.js 5181
```

要改内容：动 `source/toc.txt`（目录）或 `source/supplements/`（补充材料），
再跑一次 `tools/build_data.py` 即可。

## 已知问题

原始 Word 是扫描识别稿，正文里有个别错字（如「安微大学」「授子」），以及少数标题被并进
相邻段落。这些保持原样，没有替学校改写；正式引用请以印发版本为准。
